Домашнее задание к работе 4
Условие задачи
Друзья заказали пиццу. Они решают, резать её на 4 или 6 кусков, по простому правилу:
если ровно один из них (Ваня A или Петя B) проголодался (его «уровень голода» —
чётное число), то резать на 4 части. Запишите условие для нарезки на 4 части.

1. Алгоритм и блок-схема

Алгоритм
1. Начало.
2. Объявить переменные:
   ○ A — уровень голода Вани.
   ○ B — уровень голода Пети.
3. Ввести исходные данные:
   ○ A — уровень голода Вани (целое число).
   ○ B — уровень голода Пети (целое число).
4. Проверить условие:
   ○ «ровно один проголодался» — значит ровно у одного из A и B
     уровень голода чётный.
   ○ Условие нарезки на 4 части:
     (A % 2 == 0 && B % 2 != 0) || (A % 2 != 0 && B % 2 == 0)
5. Если условие истинно:
   ○ вывести «резать пиццу на 4 части».
   Иначе:
   ○ вывести «резать пиццу на 6 частей».
6. Конец.

2.Реализация программы

#define _CRT_SECURE_NO_DEPRECATE 
#include <stdio.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "RUS");

    int A, B;   

    printf("Введите уровень голода Вани (A): ");
    scanf("%d", &A);

    printf("Введите уровень голода Пети (B): ");
    scanf("%d", &B);

   
    if ((A % 2 == 0 && B % 2 != 0) || (A % 2 != 0 && B % 2 == 0))
    {
        printf("Условие выполнено: резать пиццу на 4 части.\n");
    }
    else
    {
        printf("Условие не выполнено: резать пиццу на 6 частей.\n");
    }

    return 0;
}
